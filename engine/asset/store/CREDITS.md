# Credits

`src/synonyms/wordnet.rs` contains a synonym table extracted from Princeton
WordNet 3.1, Copyright 2011 by Princeton University. The extract keeps only
synset membership from the adjective files and selected noun and verb files.
Groups contain 2–12 single lowercase ASCII alphanumeric words.

WordNet 3.1 full notice: `LICENSES/WordNet-3.1.txt`.
